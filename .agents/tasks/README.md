# SISO Librarian — `.agents/tasks/`

Open engineering work owned by this repository. Adopts the SISO org
`.agents/tasks/` convention: one task per `backlog/TASK-NNNN/task.json`
validated against `task_schema.json`, with `status` canonical.

Seeded 2026-08-07 from the first independent review of all 17 proposals — until
then, as the librarian itself recorded, "There are now 17 proposals in this repo
and zero have been independently reviewed. I am the only reader."

Sixteen of seventeen survived review intact. The seventeenth, the flagship cache
proposal, **survived as a finding and failed as an executable**: its measurement
reproduces, its patch anchor no longer matches the code it patches.

`consolidation-source/LIBRARIAN-REVIEW.html` is the full review, copied in so it
outlives the session that produced it.
