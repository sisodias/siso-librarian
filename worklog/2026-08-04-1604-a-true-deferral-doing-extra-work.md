# Worklog: a true deferral doing extra work

Date: 2026-08-04T16:04:33Z (generated filename)
Thread: the tenth deferral

## The one I expected to survive

> *"A 1900 Twain edition is almost certainly public domain despite absent
> metadata — and asserting that is a **copyright determination**, not a query
> fix. It is not mine to make on someone else's behalf, however confident I am."*

**It stands.** Asserting a work is public domain when its metadata does not say
so is a legal judgement, and confidence is not authority. Ten deferrals tested
and this is the first whose *substance* survives intact.

## But it was doing extra work

I never asked the obvious follow-up: **how many candidates need no determination
at all?**

```
mediatype:texts AND rights:"public domain" AND language:eng
  NOT collection:printdisabled NOT collection:inlibrary

  270,049   (270,046 this morning — live and growing)
```

Every one carries an **explicit rights field set by the Internet Archive**. The
determination is already made, upstream, by the party entitled to make it.

So IA expansion is **not blocked on a copyright call**. Only the sparse-metadata
subset — the Twain case — is. A quarter of a million texts are not waiting on
anything I cannot decide.

## What is actually blocked

Selection. I measured this earlier today and did not connect it: the head of the
explicit pool is **ephemera** — student newspapers, sales catalogues, family
photographs. Choosing which of 270,049 the Library wants is a **curation**
decision, not a legal one.

Those need different people and different arguments. I had filed both under one
sentence about copyright.

| Measurement | Value |
| --- | ---: |
| deferral substance | **holds** |
| deferral scope | overstated |
| texts needing no determination | **270,049** |
| real blocker | selection, not rights |

Escalation corrected in place; verify exit 0.

## Ten for ten, with a distinction

Nine deferrals were wrong in scope. This one is **right in substance and wrong
in reach** — the first where the sentence itself is defensible and the work it
prevented was not.

That is the more dangerous kind. A wrong claim invites correction; a true claim
doing more work than it should just quietly stops things.
